# 効果文の不足一覧

`effects-ja.json`（非公開データ）に記録があるカードのうち、信頼できる効果文
（`source` が `ingame` または `aosns`）が無い level を一覧化したもの。効果文
そのものは記載しない（非公開データのため）。カード名と level 番号のみ。

**判定基準**: `source` が `gamerch` のみの level は「未登録」として扱う
（gamerchは効果文そのものではなく変化点の要約であることが判明したため）。

**対象範囲について**: この一覧は `effects-ja.json` に一度でも記録がある
カードのみを対象にしている。一度も記録が無いカード（gamerchでもaosnsでも
一切触れられていないカード）はここには出てこない。そのため「ここに出て
いない＝完璧」を意味しない。
