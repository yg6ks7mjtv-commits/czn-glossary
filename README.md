# カオスゼロナイトメア 英日用語対応表

Chaos Zero Nightmare の状態異常・バフ・デバフ用語の英日対応表。

## ファイル

- `glossary.json` — 用語対応表本体

## スキーマ

```json
{
  "en": "Morale",
  "ja": "士気",
  "confidence": "confirmed",
  "source": "確認したURL",
  "note": "任意。guess の場合は根拠を必ず記載"
}
```

### confidence の値

| 値 | 意味 |
|---|---|
| `confirmed` | 英語ページと日本語ページの**効果説明文を突き合わせて一致を確認**したもの |
| `guess` | 説明文の一致は未確認。語感・見た目・文脈からの推測。`note` に根拠を必ず書く |
| `unmatched` | 日本語側のみ確認。対応する英語用語が特定できていない（`en` は空欄） |

**推測を `confirmed` にしないこと。** 説明文の一致を自分で確認していないものは、
どれだけもっともらしくても `guess` 止まりにする。

### データの出どころ

- **日本語 48 件** — ユーザーが gamerch の状態異常・バフデバフ一覧
  （**2026/04/14 時点**）から転記して提供したもの。
- **英語対応 41 件** — ユーザーが Prydwen の
  [用語辞典](https://www.prydwen.gg/chaos-zero-nightmare/guides/effects-dictionary)
  の効果説明文と突き合わせて確認し、提供したもの。
- **`source` が `user-verified` の 2 件**（`ストレス` / `欲望カード`）— 初回に
  事前確認済みとして提供されたペア。上記どちらの一覧にも含まれていないため、
  出典 URL を特定できていない。

この作業を行ったセッションでは egress ポリシーにより `gamerch.com` および
`www.prydwen.gg` への接続が拒否され（CONNECT に 403）、出典ページを直接読んだ
検証は行っていない。**`confirmed` の根拠はすべてユーザーによる確認。**

## 既知の欠落

- **日本語一覧は 2026/04/14 時点のもので、シーズン4以降に追加された用語
  （点火 など）は含まれていない。** 最新シーズンの用語を追う場合は
  出典ページを再取得して差分を追加すること。
- **未解決 7 件** — `気絶` / `挑発` / `隠蔽` / `毒` / `氷結` / `妄想` /
  `クリスタライズ`。いずれも敵が付与する状態異常系で、Prydwen の用語辞典に
  未収載。別ページまたは別ソースでの確認が必要。
  - `クリスタライズ` は当初 `Crystallize` として `confirmed` で登録していたが、
    辞典に該当項目が無いことが判明したため `unmatched` に降格した。
- `ストレス` と `欲望カード` の 2 件は 48 件の一覧にも辞典の対応表にも
  含まれていないが、ユーザー確認済みのため `confirmed` のまま据え置いている。
  合計が 48 ではなく 50 なのはこのため。

## 修正履歴

- `不屈` の英語は `Indomitability` ではなく **`Fortitude`**（用語辞典で確認）。
- `クリスタライズ` を `confirmed`（`Crystallize`）から `unmatched` に降格。
