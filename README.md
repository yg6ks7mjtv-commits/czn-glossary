# カオスゼロナイトメア 英日用語対応表

Chaos Zero Nightmare の状態異常・バフ・デバフ用語の英日対応表。

## ファイル

- `glossary.json` — 用語対応表本体

## スキーマ

```json
{
  "en": "Morale",
  "ja": "士気",
  "confidence": "confirmed",
  "source": "確認したURL",
  "note": "任意。guess の場合は根拠を必ず記載"
}
```

### confidence の値

| 値 | 意味 |
|---|---|
| `confirmed` | 英語ページと日本語ページの**効果説明文を突き合わせて一致を確認**したもの |
| `guess` | 説明文の一致は未確認。語感・見た目・文脈からの推測。`note` に根拠を必ず書く |
| `unmatched` | 日本語側のみ確認。対応する英語用語が特定できていない（`en` は空欄） |

**推測を `confirmed` にしないこと。** 説明文の一致を自分で確認していないものは、
どれだけもっともらしくても `guess` 止まりにする。

### データの出どころ

- **日本語 48 件** — ユーザーが gamerch の状態異常・バフデバフ一覧
  （**2026/04/14 時点**）から転記して提供したもの。
- **`source` が `user-verified` の 12 件** — ユーザー提供の事前確認済みペア。
  URL ではなく `user-verified` としてあるのは、確認したのがユーザーであり、
  この作業を行ったセッションでは出典ページを読んでいないため。出典に
  アクセスできる環境で再検証し、実際に確認した URL に置き換えること。

いずれも作業セッション側では出典ページに未アクセス。理由は、実行環境の
egress ポリシーにより `gamerch.com` および `www.prydwen.gg` への接続が
拒否されたため（CONNECT に 403）。許可されていたのは GitHub と
パッケージレジストリのみ。

## 既知の欠落

- **この一覧は 2026/04/14 時点のもので、シーズン4以降に追加された用語
  （点火 など）は含まれていない。** 最新シーズンの用語を追う場合は
  出典ページを再取得して差分を追加すること。
- `ストレス` と `欲望カード` の 2 件は上記 48 件の一覧に含まれていないが、
  ユーザー確認済みのため据え置いている（別ページ由来と思われる）。
  合計が 48 ではなく 50 なのはこのため。
